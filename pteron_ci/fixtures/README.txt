Answers from YouTube used by the tests (innertube.rs, fixtures_parse).
search-*.json, next-*.json, player-*.json must parse; player-no-*.json and search-changed.json must be refused.
To add real ones: run Pteron with PTERON_RECORD_DIR=<folder> set, search and open a video, then copy the saved
<endpoint>-<n>.json files here as search-<name>.json / next-<name>.json / player-<name>.json.
The samples here are small hand-made ones in the same shape.
